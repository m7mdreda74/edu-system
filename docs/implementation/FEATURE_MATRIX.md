# Feature Matrix

Status values: existing, partial, missing, security gap, deferred.

| Feature | Current evidence | Status | Implementation decision |
| --- | --- | --- | --- |
| Public grade/subject/teacher discovery | `Public/*Controller`, `BrowseFlowTest`, `TeacherDirectoryController` | existing | Preserve and regression-test. |
| Group subscriptions and pricing | `SubscriptionService`, `TeachingGroup`, checkout routes | existing | Reuse; no duplicate course model. |
| Private booking and slot conflicts | `SessionBookingService`, private slot routes/tests | existing | Reuse; later concurrency verification on MySQL. |
| Curriculum units and lesson materials | `CurriculumController`, `Curriculum.vue`, Blob upload service | partial | Existing protected curriculum is reused; Continue Learning now consumes published lesson/progress records. |
| Worksheets and grading | `WorksheetController`, `LearnController`, `WorksheetSubmission`, `TeacherGradebookService`, `Teacher/Gradebook.vue` | partial | Existing upsert/grading is preserved; the read-only unified Gradebook and teacher-scoped CSV export are available, while large-dataset pagination remains follow-up hardening. |
| Quizzes and server-side grading | `QuizService`, `QuizController`, `TeacherGradebookService`, `QuizAttempt`, `GenericDatabaseNotification`, quiz builder | improved checkpoint | Preserve server-side scoring and attempt history; submitted attempts now support owner-scoped teacher feedback exposed to permitted student/parent/Gradebook surfaces, with one in-app release notification to the student and verified linked parents, while scheduling/configuration gaps remain. |
| Protected learning files/videos | `ProtectedFileController`, `MaterialPolicy`, signed routes | existing with security boundary | Keep server-side checks; add regression coverage where changed. |
| Parent child monitoring | `ParentDashboardController`, `StudentAssignmentService`, `ParentProgressReportService`, `LearningOutcomeProgressService`, `Parent/Dashboard.vue`, parent portal tests | implemented checkpoint | Verified-child switching, attendance, quiz/submission results, payments, active homework statuses, rolling seven-day current/previous explainable comparisons, and active-curriculum learning-outcome progress are read-only. |
| Parent/student linking | `ParentStudentLinkService`, `parent_student_links` | improved, migration pending | Pending request, student approval/rejection, expiry, audit, revocation, generic response, and rate limiting are implemented; migration still needs controlled release. |
| Teacher operational dashboard | `Teacher/DashboardController`, `Teacher/Dashboard.vue` | partial, improved | Existing aggregates plus real pending-grading count and worksheet navigation. |
| Student dashboard | `Student/DashboardController`, `Student/Dashboard.vue` | partial, improved | Pending link decisions, real Continue Learning, and Assignment Center navigation are implemented. |
| Student assignment center | `StudentAssignmentService`, `Student/Assignments.vue`, `AssignmentsTest` | implemented checkpoint | Active subscriptions, published homework, progress/submission statuses, protected files, filters, and empty states use real records. |
| Student assessment center | `StudentAssessmentService`, `Student/Assessments.vue`, `AssessmentsTest` | implemented checkpoint | Published active-subscription quizzes, availability windows, attempt state, result history, and summary metrics are read-only; quiz submission and grading remain in the existing server-side flow. |
| Unified gradebook | `TeacherGradebookService`, `Teacher/GradebookController`, `Teacher/Gradebook.vue`, `GradebookTest` | implemented checkpoint | Read-only aggregate of submitted homework and latest submitted quiz attempt, teacher-scoped, with database-level pagination, full-scope summary totals, explicit missing-submission semantics, and a protected CSV export. |
| Teacher performance analytics | `TeacherPerformanceAnalyticsService`, `LearningOutcomeProgressService`, `PerformanceAnalyticsController`, `Teacher/PerformanceAnalytics.vue`, `PerformanceAnalyticsTest` | implemented checkpoint | Teacher-owned roster analytics for attendance, completed lessons, study time, submitted/missing homework, quiz history, averages, trends, explainable attention signals, published learning-outcome status aggregation, and filtered UTF-8 CSV export with formula neutralization. |
| Question bank | `QuestionBankService`, `Teacher/QuestionBank.vue`, `QuizBuilderController`, `QuestionBankTest` | implemented checkpoint | Teacher-owned private/shared reusable questions with scoped metadata, ordered options, explicit copy permissions, and immutable quiz snapshots; migration and staging smoke remain pending. |
| Educational resource library | `ResourceLibraryService`, `LearningResourcePolicy`, teacher/admin/student resource pages, `ResourceLibraryTest`, `CurriculumBlobUploadTest` | implemented checkpoint | Teacher-owned searchable resources support local or direct private Blob upload, normalized tags, assignment attachment, protected student/verified-parent access, and admin approval before cross-teacher sharing; migration, Blob/OIDC, and staging smoke remain pending. |
| Announcements/academic alerts | `GroupAnnouncementService`, `AcademicAlertService`, `AcademicAlertNotification`, `Teacher/Announcements.vue`, `AnnouncementsTest`, `AcademicAlertTest` | implemented checkpoint | Teacher-owned announcements plus configurable queued in-app alerts for homework, classes, absences, assessment decline, and subscription expiration; active students and verified linked parents receive scoped copies with recipient-level deduplication; owner-only announcement editing/deletion and scoped CSV export are available, while push/SMS remains deferred. |
| Student achievements | `StudentAchievementService`, `Student/DashboardController`, `Student/Dashboard.vue`, `Student/DashboardTest`, `LEARNING_GAMIFICATION_ENABLED` | implemented checkpoint, disabled by default | Private points, levels, milestones, badges, and scoped non-repeat counts use active-subscription records; no public leaderboard or external data transfer. |
| Learning Outcomes | `LearningOutcome`, `LearningOutcomeProgressService`, `CurriculumController`, `LearnController`, parent/curriculum/Study Room pages, focused tests | implemented checkpoint, migration pending | Lightweight teacher-owned objectives attach to a unit, lesson, or electronic assessment; only published outcomes within an authorized subscribed group or verified parent's active-child report are shown, with shared status derived from lesson/quiz records. |
| AI integrations | No approved provider, privacy review, or configured infrastructure | deferred | Do not add appearance-only integrations or send identifiable student data externally. |
| Vercel/serverless storage | `CurriculumBlobUpload`, `api/blob-*`, `vercel.json` | existing but environment-dependent | Preserve; production Blob/OIDC smoke test remains external. |
