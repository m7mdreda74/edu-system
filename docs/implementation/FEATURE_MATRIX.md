| --- | --- | --- | --- |

| Group subscriptions and pricing | `SubscriptionService`, `TeachingGroup`, checkout routes | existing | Reuse; no duplicate course model. |

| Protected learning files/videos | `ProtectedFileController`, `MaterialPolicy`, signed routes | existing with security boundary | Keep server-side checks; add regression coverage where changed. |

| Student assessment center | `StudentAssessmentService`, `Student/Assessments.vue`, `AssessmentsTest` | implemented checkpoint | Published active-subscription quizzes, availability windows, attempt state, result history, and summary metrics are read-only; quiz submission and grading remain in the existing server-side flow. |
| Unified gradebook | `TeacherGradebookService`, `Teacher/GradebookController`, `Teacher/Gradebook.vue`, `GradebookTest` | implemented checkpoint | Read-only aggregate of submitted homework and latest submitted quiz attempt, teacher-scoped, with database-level pagination, full-scope summary totals, explicit missing-submission semantics, and a protected CSV export. |

| Announcements/academic alerts | `GroupAnnouncementService`, `AcademicAlertService`, `AcademicAlertNotification`, `Teacher/Announcements.vue`, `AcademicAlertTest` | implemented checkpoint | Teacher-owned announcements plus configurable in-app alerts for homework, classes, absences, assessment decline, and subscription expiration; active students and verified linked parents receive scoped copies with recipient-level deduplication; push/SMS and editing/export remain deferred. |
| Gamification/AI integrations | No safe configured infrastructure found | deferred | Do not add appearance-only integrations. |
| Vercel/serverless storage | `CurriculumBlobUpload`, `api/blob-*`, `vercel.json` | existing but environment-dependent | Preserve; production Blob/OIDC smoke test remains external. |
